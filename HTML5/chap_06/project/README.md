## 실행 방법

저장소 폴더 구조를 유지한 채 각 HTML을 브라우저에서 엽니다. 가위바위보는 입력창에 0, 1, 2 중 하나를 입력하고, 다시 실행하려면 페이지를 새로고침합니다. 입력은 `parseInt`로 변환하며 변환 결과가 0~2가 아니거나 취소하면 게임 결과를 출력하지 않습니다.

글자색 변경은 `red`, `blue`, `#008000` 등의 CSS 색상 값을 입력하고 Start 버튼을 누릅니다. 입력값을 그대로 `style.color`에 대입하며 별도의 오류 안내는 없습니다.

게임 이미지는 `../media/rpc0.png`, `../media/rpc1.png`, `../media/rpc2.png`를 사용합니다. 제출 ZIP에는 CSS와 이미지가 포함되어 있지 않으므로 ZIP만 풀어서는 원본과 같은 스타일·이미지가 표시되지 않습니다. 저장소 안의 HTML로 실행하거나 같은 상대 경로에 필요한 자료를 배치합니다.
